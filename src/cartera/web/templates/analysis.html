No model configured

This installation has no analysis backend, which is the shipped state and not a fault: nothing else in this tool needs a model. Every other page computes its own figures in code.

To enable the narration, set these in the environment file and restart:

CARTERA_LLM_BASE_URL="http://127.0.0.1:8080/v1"
CARTERA_LLM_MODEL="qwen3-4b"

Any OpenAI-compatible endpoint will do: llama.cpp, Ollama and vLLM all speak this shape. Keep it local if the portfolio is private — the figures leave this machine when the model is remote. The API key, if the endpoint needs one, belongs in the keyring under CARTERA_LLM_API_KEY, never in the file.
